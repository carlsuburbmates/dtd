Dog Trainers Directory

Connecting dog owners with independent dog trainers across Greater Melbourne through automated discovery and guided matching.

About the Platform

Dog Trainers Directory (DTD) is a digital-native technology platform and discovery directory designed for Greater Melbourne. The service allows dog owners to browse curated local trainers by suburb, filter by training philosophy and behavioral specialty, and submit direct enquiries with zero intro or commission fees.

Technology & Cloud Infrastructure

Dog Trainers Directory is built as a modern cloud-native web application hosted on Google Cloud Platform:

  • Frontend: React Single-Page Application deployed via Google Firebase Hosting.
  • Backend API: Containerized Python service hosted on Google Cloud Run (Health check: /api/health).
  • Database & Telemetry: MongoDB Atlas cloud database and Sentry application monitoring.
